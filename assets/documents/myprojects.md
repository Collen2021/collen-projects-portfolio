## Project 1 – 3G Network Expansion Program
Led business analysis and project delivery activities for a large-scale telecommunications network expansion program valued at over USD $200 million. The project included the deployment of more than 1,000 3G base stations, installation of new Base Station Controllers (BSCs), and extensive civil infrastructure works, including rooftop sites, greenfield lattice towers, and shared tower deployments. The software scope included the implementation of a new Operations Support System (OSS) to enable centralized monitoring, configuration, and management of the network from the Network Operations Center (NOC), improving network visibility, operational efficiency, and service reliability. 

## Project 2 – OSS/ Network Management System Implementation
Led business analysis and project coordination for the implementation of a centralized Network Management System (NMS) supporting the operator's 2G and 3G wireless networks. The solution enabled centralized monitoring, configuration, fault management, performance monitoring, and software management of thousands of network elements, including Base Transceiver Stations (BTSs), Base Station Controllers (BSCs), and transmission equipment. The project also included the design and implementation of API integrations with OSS/BSS platforms and other enterprise systems to automate alarm management, inventory synchronization, performance reporting, ticket creation, and operational workflows. Responsibilities included requirements elicitation, process mapping, stakeholder management, vendor coordination, API and interface requirements, system integration, user acceptance testing (UAT), and production rollout. The solution improved network visibility, reduced fault resolution times, increased network availability, and enhanced operational efficiency for the Network Operations Center (NOC).

## Project 3 - Warehouse Management System (WMS) | Software Development 
Led business analysis and project delivery for the design and implementation of an enterprise Warehouse Management System (WMS) to optimize end-to-end supply chain and warehouse operations. The solution included modules for inbound receiving, put-away, on-hand inventory management, outbound order fulfillment, picking, packing, shipping, stock transfers, replenishment, cycle counting, physical inventory, inventory audits, returns (reverse logistics), lot and serial number tracking, barcode scanning, location/bin management, and inventory adjustments. Collaborated with supply chain stakeholders to define business requirements, map warehouse processes, and develop functional specifications. Managed API integrations with ERP, procurement, transportation, and reporting systems to enable real-time inventory visibility and automated transaction processing. Coordinated Agile delivery, UAT, production deployment, and post-implementation support, improving inventory accuracy, warehouse productivity, order fulfillment efficiency, and supply chain visibility.

## Project 4 - Enterprise Cloud Migration Project | On-Premises to the Cloud
Led business analysis and project coordination for a large-scale cloud migration initiative to transition enterprise applications from locally hosted servers to the Cloud. The project involved migrating application workloads, databases, middleware, and supporting infrastructure from traditional data center environments to a scalable and secure cloud architecture. Collaborated with application owners, infrastructure teams, cloud architects, security teams, and vendors to assess application dependencies, define migration strategies, document requirements, and support migration planning. Managed activities including application discovery, server provisioning, data migration, environment configuration, integration testing, performance validation, and production cutover. Supported cloud infrastructure setup including compute resources, storage, networking, security controls, backup, disaster recovery, and monitoring capabilities. Coordinated SIT, UAT, defect management, deployment, and post-migration stabilization, improving application scalability, availability, operational efficiency, and reducing reliance on physical infrastructure.

## Project 5 - Broadband Customer Portal Enhancement | Business Support System (BSS)
Enhanced an existing Business Support System (BSS) customer portal to improve the digital experience for broadband subscribers and streamline customer service operations. Worked with product owners, business stakeholders, customer support teams, and development teams to identify improvement opportunities, define business requirements, and translate needs into user stories, use cases, acceptance criteria, and functional specifications. The enhancements introduced new capabilities for customer account management, service plan updates, broadband service requests, billing inquiries, service status tracking, trouble ticket submission, notifications, and self-service support functions. Collaborated with technical teams on API integrations with backend systems to enable real-time customer information, service provisioning workflows, and automated transactions. Supported Agile delivery activities including backlog refinement, sprint planning, UAT, defect management, and production deployment, improving customer experience, reducing support workload, and increasing operational efficiency.

## Project 6 -Process Automation for Supply Chain & Procurement

Led a process automation initiative to streamline manual supply chain and procurement operations using APIs and Robotic Process Automation (RPA). Conducted process discovery workshops to document and analyze end-to-end workflows, including supplier deliveries, Purchase Requisitions (PR), Purchase Orders (PO), Delivery Note (DN) approvals, invoice submission, and payment processing. Identified automation opportunities, documented business requirements, and collaborated with stakeholders to redesign processes for greater efficiency and compliance. APIs enabled seamless integration between enterprise systems, while RPA automated repetitive, rules-based tasks, reducing manual effort, errors, and processing time. Facilitated requirements gathering, process mapping, solution design, UAT, and stakeholder engagement to deliver scalable automation solutions that improved operational visibility and procurement cycle times.


## Project 7 - Network Inventory Management System (NIMS) | Telecommunications OSS
Designed and enhanced a Network Inventory Management System (NIMS) to provide centralized visibility and lifecycle management of telecom network assets and resources. Collaborated with cross-functional boundary partners, including network engineering, operations, architecture, IT, and business teams, to gather requirements, analyze processes, and define solution capabilities. Supported management of key inventory objects including sites, equipment, shelves, cards, ports, circuits, etc. Developed workflows for asset onboarding, provisioning, configuration updates, reconciliation, and decommissioning. Defined user stories, data models, business rules, and integration requirements for OSS/BSS platforms. Supported API integrations, data migration, system testing, and UAT activities, improving network data accuracy, operational visibility, and resource management across the organization.

## Project 8 - Cybersecurity Metrics Monitoring and Compliance Project
Designed and implemented a Cyber Metrics Monitoring framework to strengthen security visibility, compliance measurement, and enterprise risk management. Collaborated with cybersecurity teams, application owners, infrastructure teams, and cross-functional stakeholders to define security metrics, establish data requirements, and align measurement criteria with organizational security objectives. Leveraged security platforms including Splunk, CrowdStrike, Tanium, Imperva, Qualys, Zscaler, Veracode, and JFrog Xray to enable data collection, analysis, and reporting. Developed approximately 40 cybersecurity metrics covering vulnerability management, endpoint protection, application security, logging compliance, threat detection, and security posture monitoring. Facilitated requirements workshops, metric validation sessions, documentation, and stakeholder coordination to improve compliance readiness, risk visibility, and cybersecurity operational effectiveness.

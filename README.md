# Collen Projects Portfolio

This repository contains a simple personal portfolio website designed for GitHub Pages.

## Files
- [index.html](index.html) — main content and sections for the portfolio
- [styles.css](styles.css) — visual styling and responsive layout
- [.github/workflows/deploy.yml](.github/workflows/deploy.yml) — GitHub Actions workflow for publishing to GitHub Pages

## Customize it
- Replace the placeholder contact email in [index.html](index.html)
- Update the project cards and bio text in [index.html](index.html)
- Adjust colors and layout in [styles.css](styles.css)

## Publish to GitHub Pages
1. Commit and push these files to GitHub.
2. Open your repository on GitHub and go to Settings → Pages.
3. Under Build and deployment, select GitHub Actions.
4. The workflow will deploy the site automatically on every push to the main branch.

Your site will be available at:
- https://<your-username>.github.io/collen-projects-portfolio/
